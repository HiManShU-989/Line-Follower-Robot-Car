# 🤖 Line Follower Robot Car

## 📌 Introduction
The **Line Follower Robot Car** is an autonomous robotic vehicle designed to follow a black line on a contrasting surface. It's a great introduction to robotics, automation, and embedded systems, often used in educational and research environments.

## ✨ Features
- 🧠 **Autonomous Navigation**
- ⚙️ **IR Sensor-based Line Detection**
- 🔄 **Real-time path tracking**
- 🚗 **Motor driver for wheel control**

## 🛠️ Components Used
- **Arduino UNO**
- **IR Sensors**
- **L298N Motor Driver Module**
- **DC Motors**
- **Chassis, Wheels, Battery Pack**

## 🔌 Circuit and Working
The IR sensors detect the black line and send signals to the Arduino, which processes the input and sends commands to the L298N motor driver to move the motors accordingly. When the car deviates from the path, it automatically corrects itself to stay aligned with the line.

## 🚀 How to Run
### 1️⃣ Assemble the Hardware
- Connect the components as per the circuit diagram.
- Ensure motors and sensors are correctly powered and placed.

### 2️⃣ Upload the Code
- Open the Arduino IDE.
- Upload the line follower code to your Arduino UNO.

### 3️⃣ Place the Car on Track
- Use black tape or a black line on a white surface.
- Switch on the robot and watch it follow the line!
